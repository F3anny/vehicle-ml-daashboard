# Fleetwise — Vehicle ML Django Dashboard

Implementation of the supplied Vehicle ML Django Dashboard tutorial: Django project `config`, app `vehicles`, CSV source in `dummy_data/vehicles_data_1000.csv`, pandas manufacturer frequency table, template at `vehicles/templates/vehicles/index.html`, and the dashboard at `/`.

The frontend adds a responsive workspace layout, Plotly charts, summary statistics, manufacturer/fuel/search filters, a vehicle preview, and CSV export of the current selection. Bootstrap and Plotly are served locally. Google Fonts are optional; system fonts work offline.

## Run on Windows

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open http://127.0.0.1:8000/. If PowerShell blocks activation, use `venv\Scripts\python.exe` in place of `python`; activation is optional.

## Data

The tutorial references a CSV but does not supply it. This project includes 1,000 deterministic **synthetic demo records** generated by `python dummy_data/generate_data.py`. No real market prices or fleet records are represented. The tutorial describes data analysis, not model training; the project does not claim predictive capabilities.

To replace the sample, keep these columns: `vehicle_id`, `manufacturer`, `model`, `year`, `fuel_type`, `mileage_km`, `price_usd`. Numeric columns must contain numbers; required fields cannot be empty. The dashboard reloads the file on each request. Inventory previews 20 records; export includes every matching record.

## Validate

```powershell
python manage.py check
python manage.py test
```

Development settings default to localhost and DEBUG on. For hosting, set a private `DJANGO_SECRET_KEY`, set `DJANGO_DEBUG=0`, configure allowed hosts, and serve collected static files using a production web server.
